# K-pop 아이돌의 사회적 논란과 팬덤의 온라인 발화

> 본 저장소는 「K팝 아이돌의 사회적 논란과 팬덤의 온라인 발화: 디시인사이드 아이돌 갤러리 분석」(한국사회학 60(4)) 연구에서 구축하고 분석에 활용한 연구자료 및 관련 정보를 공개하기 위한 저장소이다. 

* **구체적으로 다음과 같은 자료를 제공한다.**

1. 아이돌–디시인사이드 갤러리 매칭 테이블 (idol_gallery_matching)
분석 대상 아이돌의 특성 및 각 아이돌의 디시인사이드 갤러리를 연결한 자료이다. 아이돌 명, 세대, 활동유형, 갤러리명, 갤러리 유형, 갤러리 URL 및 자료 수집 기간 등의 정보를 포함한다.
2. 크롤러 (crawler)
디시인사이드 아이돌 갤러리 데이터 수집에 사용한 크롤러 코드이다. 
3. 월별 집계 패널 데이터 (monthly_panel)
아이돌 특성과 디시인사이드 아이돌 갤러리에서 수집한 게시물 자료를 연구 목적에 맞게 처리하고 월별로 집계한 패널 데이터를 포함한다.
4. 사회적 논란 사건 목록 (social_controversies)
분석 대상 아이돌과 관련하여 본 연구의 기준에 따라 수집·정리한 사회적 논란 사건의 구체적인 목록을 포함한다.

* **자료의 구축**

본 저장소에 포함된 자료는 연구자가 연구 목적에 따라 직접 수집·정리·코딩·가공하여 구축하였다.
디시인사이드 관련 자료의 경우, 연구에서 설정한 수집 기준과 기간에 따라 자료를 수집하고, 분석 단위에 맞게 정제 및 집계하였다. 아이돌의 특성 및 갤러리 정보 역시 분석 대상과 자료 수집 체계에 맞추어 구축하였다.
사회적 논란 사건의 경우 공개적으로 확인 가능한 자료(Namuwiki, 뉴스기사 등)를 바탕으로 연구에서 설정한 기준에 따라 사례를 식별하고 정리하였다. 

* **유의사항**

본 저장소에 포함된 자료 중 일부는 공개적으로 이용 가능한 온라인 자료를 수집·정리하여 구축한 것이다. 따라서 원자료가 게시된 웹사이트의 콘텐츠 자체를 재배포하는 것이 아니라, 연구자가 해당 자료를 연구 목적으로 수집·가공하여 생성한 데이터와 관련 정보를 제공한다.
온라인 플랫폼에서 수집된 자료의 특성상 플랫폼의 게시물 삭제, 수정, 접근 제한 및 운영정책의 변경 등으로 인해 연구 당시의 원자료 수집 환경을 완전히 재현하는 데에는 한계가 있을 수 있다.

* **인용**

본 저장소의 자료를 학술적 연구에 활용하는 경우 원 논문을 함께 인용해 주시기 바란다.
